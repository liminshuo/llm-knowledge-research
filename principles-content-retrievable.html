内容可检索

确保搜索引擎爬虫与 AI 爬虫可通过静态 HTML 或服务端渲染（SSR）获取完整正文，不依赖客户端执行 JavaScript。禁止无限滚动、动态渲染主体、虚拟滚动与关键文字内容的懒加载。 找的到 · 序号 2 · 对应 实测问题 · 检索阶段 · 完整条目见 全量亲和原则 #2。

设计UI调整

调整建议

  • 禁止设计无限滚动交互：文档页面不使用无限滚动加载更多内容的设计模式，内容分页或一次性完整展示。

页面交互

文档内容调整

调整建议

  • 静态 / SSR 可达：文档内容必须确保传统的搜索引擎爬虫和 AI 爬虫能够通过静态 HTML 或服务端渲染（SSR）的方式获取到完整的、不依赖客户端执行 JavaScript 的内容。
  • 具体禁止：无限滚动、动态渲染（页面主要内容不能完全依赖 JavaScript 客户端渲染）、虚拟滚动、关键内容的懒加载。

调整示例

Before · 依赖客户端渲染

禁用 JS 后抓取结果

<body>
  <div id="app"></div>
  <script src="/bundle.js"></script>
</body>

正文由 JS 注入，web_fetch / 静态爬虫拿到空壳页面。

After · SSR 完整正文

禁用 JS 后抓取结果

<body>
  <h1>Ascend C 算子开发</h1>
  <p>本文介绍算子开发基本流程…</p>
  <pre><code class="language-cpp">…</code></pre>
</body>

标题、正文、代码块均在首屏 HTML 中，无需执行 JavaScript。

前端调整

调整建议

  • SSR 完整输出页面主体内容：所有文档正文、标题、代码块、表格必须在服务端渲染到首屏 HTML，禁止依赖客户端 JS 渲染主体内容。
  • 禁止关键内容懒加载：图片懒加载可以保留，但文字内容（正文、步骤、警示块、验证区块）禁止懒加载，必须随页面 HTML 直接输出。
  • 禁止虚拟滚动：长列表、长表格禁止使用虚拟滚动组件，必须完整输出所有行的 DOM 节点。
  • 爬虫可达性验证：在 CI/CD 流程中加入静态 HTML 完整性检测，禁用 JS 后抓取页面，对比关键内容节点是否完整存在，不完整则阻断发布。

调整示例

1. 关键文字禁止懒加载

Before

HTML 源码

<section data-lazy-load="steps"></section>
<script>fetchSteps().then(render)</script>

安装步骤、警示块等文字由 JS 异步注入，静态抓取为空。

After

HTML 源码

<ol>
  <li>下载 CANN 安装包</li>
  <li>执行安装脚本</li>
</ol>
<div class="rf-note">注意：需 root 权限</div>

步骤与警示块随 HTML 直出；图片可保留 loading="lazy"。

Before

3. CI/CD 爬虫可达性检测

Before

发布流程

构建 → 部署 → 上线

未校验禁用 JS 后正文是否完整，问题上线后才发现。

After

发布流程

构建 → 无 JS 静态抓取 → 校验 h1/正文/代码块节点 → 缺失则阻断发布 → 部署

在 CI/CD 中自动对比关键内容节点，防止空壳页上线。
