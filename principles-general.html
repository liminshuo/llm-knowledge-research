UI 亲和原则列表

仅收录渲染页可见的 UI 设计改造项；源码标记、管道导出与入库规则见各维度 问题论证页。

UI 层亲和原则（渲染页改造）

维度UI 改造项渲染页呈现要求
版本外显 版本徽章 文章头部（H1 上方或旁侧）展示「CANN 9.0.0」「Ascend C」等版本与产品徽章
弃用横幅 已废弃章节在页顶展示弃用提示，并链接替代文档
图片图意 可读图片标签 信息型图片以描述性标签呈现（如「API 层级架构图」），禁止仅显示无意义文件名
图片内容转写 复杂图表下方附可见「图片内容转写」段落；成长地图等路径图可用正文有序列表等价呈现节点与关系
可见图注 图片下方展示「图1 · …」等图号与图意说明
Mermaid 呈现 流程 / 架构类图以 Mermaid 可编辑图替代不可读 PNG
装饰图标移除 纯装饰图标从正文移除，信息改由相邻文本承载
图片热区 热区文本链接列表 带热区的图片下方展示完整链接列表，覆盖全部热区跳转目标
描述性热区锚文本 每个热区链接使用描述性锚文本，禁止「区域1」「点击这里」
链接语义 描述性锚文本 链接可见文字描述跳转目标，禁止 LINK 等占位符
站外来源标注 站外链接旁附完整域名或来源标识（如 ↗ gitcode.com）
上下文链接 链接置于有上下文的句子中，或附用途说明，避免孤立「详情」
隐藏语义 · Tab Tab 标签可读 Tab 标签展示场景化文本（如「在线安装 · x86_64 · CANN 9.0.0」），禁止 Tab1/Tab2
Tab 面板全量可见 各 Tab 面板正文在页面上全量可见，纵向排列或切换时不隐藏非激活项正文
隐藏语义 · 折叠 折叠标题可读 折叠区展示有语义的标题文本（如「高级配置参数说明」），禁止空标题占位
折叠默认展开 折叠面板初始展开，步骤与说明在页面上直接可读
代码语义 行号与代码分离 行号由样式渲染，代码区不出现表格行号列
代码块 pre 呈现 代码块以 pre 区域呈现，不用 highlighttable 表格承载
代码场景标注 代码块上方可见文件名、语言与适用场景（如 kernel_add.cpp · Ascend C）
表格的结构语义 可见表题 表题写入 <caption>（如「表1 Ascend C Add算子设计规格」）；th、接口列表等见 专页
注意提示（Note）语义 Note 正文展开 提示正文在页面上完整展示，不折叠、不用 Tooltip 藏字
类型文本前缀 移除装饰图标；以「注意：」「警告：」等文字前缀标识类型
元数据字段规范 单一 H1 渲染页有且仅有一个 H1，与页面主题一致
标题层级连续 标题层级连续（H1→H2→H3），大纲结构在页面上清晰可读
标题文本自解释 H2/H3 标题文本自解释，避免孤立「概述」「说明」
文章摘要块 页头展示 60–120 字摘要，概括主题与适用读者
版本 / 产品徽章 页头展示 version、product 等版本与产品标识徽章
可见面包屑 页头展示完整 breadcrumb 文本路径
适用设备标签 适用芯片 / 算子类别在页头以标签展示
跨文档结构感知 可见面包屑 展示完整 breadcrumb 路径，消歧同名章节（如两处「环境准备」）
上下篇导航 页脚或文首展示「上一篇 / 下一篇」，锚文本描述目标章节
单文档结构感知 版式间距规范 用 CSS 间距控制版式，禁止用空段落 / 空行堆叠作间距
列表表达步骤 步骤与层级以有序 / 无序列表呈现，不用多个独立段落模拟列表
双轨交付与载体 机器可读入口 页脚或工具栏提供「机器可读版本」可见链接，指向 source 或 Markdown 入口
