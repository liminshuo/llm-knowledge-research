总原则

「当前问题」回答为什么痛；「亲和原则」回答怎么改。各语义维度页含原则描述与调整层面，指导渲染页、源码与管道分别改什么。

调整层面说明

以下三层定义适用于侧栏各语义维度页原则表中的「调整层面」列；阅读具体规则前请先理解各层含义。

UI 渲染页可见元素（用户打开页面能看到的内容与版式） 源码 源 HTML / RST / 写作模板中的结构与标记 管道 机器层转换、发布管线、站点配置

UI 指渲染出来的可视化页面——页头信息块、标签、Note 样式、Tab 是否藏字、表格表题等。源码 指作者写作层——alt、data 属性、Front Matter、语义标签。管道 指发布与机器层——双轨导出、JSON-LD、sitemap、llms.txt。同一问题可能需多层同时改：例如 Note 图标在 UI 与源码同时去掉；元数据在头部展示（UI）、Front Matter 写入（源码）、入库同步（管道）。
