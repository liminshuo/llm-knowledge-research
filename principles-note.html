Note 类型

对应 当前问题 · 注意提示（Note）类型语义。注意/警告/提示用文本表达类型；装饰图标对模型无意义，应从渲染页与源码同时移除。

亲和原则

编号原则描述级别调整层面
1源码用 data-admonition-type 标注 note / warning / tip / danger必须源码
2渲染页 Note 正文完整展开，不折叠、不 Tooltip 藏字必须UI 源码
3移除 Note 装饰图标；类型改用文本前缀「注意：」「警告：」显示在渲染页必须UI 源码
4机器层转为 Markdown 引用块（> **注意**）必须管道
