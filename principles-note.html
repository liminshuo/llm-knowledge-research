安全警示语义化

Note / 警告 / 危险等提示正文完整展开、用文字前缀标明类型，不靠折叠或图标承载语义。 能读取 · 序号 10 · 对应 问题论证 · 注意提示（Note）语义。

内容侧

警示语义转化

Note、注意、警告等警示提示正文在页面上完整展示，不折叠、不用 tooltip 藏字。

  1. 完整可见
  2. 文字前缀：警示信息必须使用文字前缀明确表示其类型，如「注意」「警告」「危险」
  3. 结构化：建议为不同类型的安全警示定义固定的 CSS 类

研发侧

结构化标记

  1. 使用 data-admonition-type="note|warning|danger" 标识警示类型

定义 Markdown 导出格式

  1. 导出为 > **注意**： 引用块格式，确保纯文本可读

示例

HTML 源码

<div class="admonition" data-admonition-type="warning">
  <span class="admonition-label">警告：</span>升级前请备份 /usr/local/Ascend。
</div>

Markdown 导出

> **警告**：升级前请备份 /usr/local/Ascend。
