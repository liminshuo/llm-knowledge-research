表格的结构语义

对应 问题论证 · 表格的结构语义（Add 算子 · 表1 设计规格）。以下仅列渲染页可见的表题、表头与接口列表 UI 改造项；Markdown 导出等管道规则见问题论证。

UI 亲和原则

编号UI 改造项渲染页呈现要求级别
1可见表题表题写入 <caption>（如「表1 Ascend C Add算子设计规格」），非仅加粗段落必须
2表头语义化I/O 子表列名使用 <th>，禁止 <td> 伪装表头必须
3接口列表独立化「使用的主要接口」以 <ul> 或表外列表呈现，禁止拆成多行伪数据行必须
