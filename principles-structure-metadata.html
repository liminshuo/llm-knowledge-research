UI 亲和原则

Front Matter、JSON-LD 与 chunk 字段等入库规则见 问题论证 · 页级元数据。

编号UI 改造项渲染页呈现要求级别
1单一 H1渲染页有且仅有一个 H1，与页面主题一致必须
2标题层级连续标题层级连续（H1→H2→H3），大纲结构在页面上清晰可读必须
3标题文本自解释H2/H3 标题文本自解释，避免孤立「概述」「说明」建议
4文章摘要块页头展示 60–120 字摘要，概括主题与适用读者必须
5版本 / 产品徽章页头展示 version、product 等版本与产品标识徽章必须
6可见面包屑页头展示完整 breadcrumb 文本路径必须
7适用设备标签适用芯片 / 算子类别在页头以标签展示建议
