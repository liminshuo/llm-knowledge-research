元数据丰富化

为每篇文档补全文档身份、版本、适用产品、更新时间、上下篇关系等元数据，并在页头展示摘要与面包屑，让机器可结构化检索、人可快速定位。 找的准 · 序号 4 · 对应 问题论证 · 页级元数据未结构化。

文档内容调整

调整建议

  • 每个文档页面建议在 <head> 中包含丰富的结构化元数据，优先使用JSON-LD格式，至少嵌入：@type（TechArticle / HowTo / FAQPage）、headline、description（150–160字符）、inLanguage、datePublished、dateModified、keywords、author/publisher。

调整示例

1. Frontmatter 中补充完整元数据字段

Before · 仅标题与版本

---
title: 算子开发入门
version: "9.0.0"
---

After · 完整结构化元数据

---
title: 算子开发入门
description: "面向已完成环境安装的开发者，介绍
  Ascend C 算子开发基本流程与工程结构。（78字）"
version: "9.0.0"
date_published: "2026-01-01"
date_modified: "2026-06-01"
in_language: zh-CN
keywords: [Ascend C, 算子开发, CANN, 入门]
author: 昇腾文档团队
schema_type: TechArticle
---

前端调整

调整建议

  • JSON-LD 模板化输出：在页面模板中统一注入 JSON-LD，字段从 CMS 结构化数据中动态读取，覆盖所有文档页面，不依赖人工逐页添加。
  • 必填字段完整性校验：发布流程中检测 JSON-LD 是否包含所有必填字段（@type、headline、description、inLanguage、datePublished、dateModified、keywords、author/publisher），缺失字段则阻断发布。
  • @type 按页面类型自动匹配：文档类型（HowTo、TechArticle、FAQPage 等）在 CMS 中作为页面属性维护，JSON-LD 的 @type 由系统根据页面类型自动填入，不依赖人工判断。

调整示例

1. JSON-LD 结构化元数据

Before · 无 JSON-LD

<head>
  <title>算子开发入门</title>
</head>

After · 完整 JSON-LD

<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "TechArticle",
  "headline": "算子开发入门",
  "description": "面向已完成环境安装的开发者介绍 Ascend C 算子开发基本流程（150字以内）",
  "inLanguage": "zh-CN",
  "datePublished": "2026-01-01",
  "dateModified": "2026-06-01",
  "version": "9.0.0"
}
</script>

2. BreadcrumbList 面包屑导航 JSON-LD

Before · 仅视觉面包屑，无结构化数据

<!-- 面包屑只在页面可见，无 JSON-LD -->
<nav class="breadcrumb">
  首页 > 开发指南 > 算子开发入门
</nav>
<!-- Agent 只能读到文字，无法推断层级关系
     和每层的 URL -->

After · BreadcrumbList 结构化层级

<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "BreadcrumbList",
  "itemListElement": [
    {
      "@type": "ListItem",
      "position": 1,
      "name": "首页",
      "item": "https://…/"
    },
    {
      "@type": "ListItem",
      "position": 2,
      "name": "开发指南",
      "item": "https://…/dev-guide/"
    },
    {
      "@type": "ListItem",
      "position": 3,
      "name": "算子开发入门",
      "item": "https://…/900/operator_dev.html"
    }
  ]
}
</script>
