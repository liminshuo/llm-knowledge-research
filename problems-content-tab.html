隐藏的语义（Tab） 抓取差

Tab 隐藏语义指被交互 UI 折叠、未进入默认抓取管道的正文——非激活 Tab 面板常被 display:none 隐藏。 以 CANN 软件下载 为例：用户切换 Tab 能看到的选型说明与安装步骤，知识库可能只入库当前默认 Tab 组合。

问题实测

1. 向模型提问

我在看 CANN 软件下载（CANN 9.0.0），想给 Atlas 800 训练款做离线安装，对应的下载命令和安装说明在哪里？

2. 大模型回答

查看大模型回答内容

3. 问题洞察

大模型的回答指向两点结论：

  • 非激活 Tab 未入库：CANN 下载页多轴 Tab 选型，非激活面板可被 display:none 隐藏——默认抓取只入库当前 Tab 组合。
  • 安装路径不完整：问「Atlas 800 离线安装命令」时，知识库可能仅有在线安装说明，离线 / 其他架构分支缺失。

根因分析

Tab 隐藏语义丢失的核心原因是：非激活面板 CSS 隐藏、Tab 维度未结构化、机器层未全量展开。

1. 非激活面板被隐藏

display:none 导致默认管道跳过 Tab 内正文。

修改建议

各面板源码完整，渲染页正文全量可见，禁止 CSS 隐藏关键内容。

2. Tab 维度未字段化

版本 / 架构 / 安装方式等选型维度未写入 chunk，检索难区分路径。

修改建议

机器层以 H3 标注各面板标题后全量展开入库。

3. 人机层未双轨

人类保留 Tab 交互，机器层缺少预展开 MD。

修改建议

RAG 优先抓取 doc_center/source 预展开 MD（见 双轨交付）。

4. 与折叠叠加断裂

Tab 选型 + 折叠指引叠加时，「不知硬件 → 不知如何选型」链路在知识库中断。

修改建议

同步落地 折叠全量展开 策略。
