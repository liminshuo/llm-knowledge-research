隐藏的语义（Tab） 抓取差

Tab 隐藏语义指被交互 UI 折叠、未进入默认抓取管道的正文——非激活 Tab 面板常被 display:none 隐藏。 以 CANN 软件下载 为例：用户切换 Tab 能看到的选型说明与安装步骤，知识库可能只入库当前默认 Tab 组合。

核心问题
  • 下载页含多轴 Tab 选型（版本、架构、发行版、在线/离线安装等），非激活面板可被 CSS 隐藏
  • 默认抓取可能只抓到当前 Tab 组合下的安装说明，离线安装、其他架构等分支正文缺失
  • Tab 标签与选型维度往往未结构化写入 chunk，检索时难以区分「用户问的是哪条安装路径」

问题实测

测试问题

读取 CANN 软件下载（CANN 9.0.0），切换版本 / 架构 / 发行版 / 安装方式等 Tab 后，非激活 Tab 面板内的选型说明与安装命令是否进入了知识库？

结论：非激活 Tab 语义未入库或截断

CANN 软件下载页是典型的多轴 Tab 场景。页面在版本、架构、发行版、安装方式等维度上组合切换；非激活面板正文与部署命令可能不在默认可见 DOM 中，默认管道跳过 display:none 区域时，知识库可能仅有「在线安装 · x86_64 · 9.0.0」一类当前组合，缺少离线安装、其他架构等分支说明。

Tab 语义对照

Tab 要素页面上入库后
当前激活 Tab 组合可见安装命令与说明可能入库（仅一条路径）
非激活 Tab 面板display:none 隐藏完全缺失
Tab 标签与选型维度交互切换可见未结构化
wget / 安装脚本等命令随 Tab 组合切换非默认组合常丢失

入库状态对照

入库环节状态说明
默认激活 Tab 正文部分入库仅当前组合可见
非激活 Tab 面板未落实管道跳过隐藏节点
Tab 全量展开缺失须机器层预展开
选型维度结构化不稳定标签未写入 chunk

解决方案

改进目标

让每个 Tab 组合下的选型说明与安装命令以独立文本 chunk进入知识库——检索「CANN 离线安装」「aarch64 下载命令」时均能召回，不要求用户在线切换 Tab，要求机器层事先全量展开。

改进措施

  • 必要Tab 全量可见：各面板源码完整，标签配有明确文本，渲染页正文全量可见；禁止使用 display: none 隐藏非激活项；
  • 必要管道层扁平输出：在机器处理层将 Tab 面板全量展开，以 H3 标签标注各面板标题后入库；
  • 可选双轨交付：RAG 优先抓取 doc_center/source 预展开 MD，人类仍保留 Tab 交互 UI。

核心原则：Tab 内容先行入库——每个 Tab 须有可读标签，正文在源 HTML 中顺序展开。详见 亲和原则 · Tab 语义。

页面渲染

wget … --install

<div class="tab-panel-active">wget ... --install</div> <div class="more-tab-item" style="display:none">...离线安装命令...</div>

知识库 chunk：可能仅有当前激活组合，离线安装与其他架构说明丢失。

✅ 亲和渲染

页面渲染

在线安装 · x86_64 · CANN 9.0.0
wget … ./Ascend-cann-toolkit_9.0.0_linux-x86_64.run --install
离线安装 · x86_64 · CANN 9.0.0
./Ascend-cann-toolkit_9.0.0_linux-x86_64.run --install --offline

HTML 源码

<h3 id="install-online-x86-900">在线安装 · x86_64 · CANN 9.0.0</h3> <pre><code class="language-bash">wget ... ./Ascend-cann-toolkit_9.0.0_linux-x86_64.run --install</code></pre> <h3 id="install-offline-x86-900">离线安装 · x86_64 · CANN 9.0.0</h3> <pre><code class="language-bash">./Ascend-cann-toolkit_9.0.0_linux-x86_64.run --install --offline</code></pre>

知识库 chunk：可检索「CANN 离线安装」「aarch64 下载命令」「9.0.0 在线安装」。

管道切片

机器层从 doc_center/source 导出时，将各 Tab 组合扁平为 H3 + 正文 chunk：

源 HTML │ ├──► 人类层：多轴 Tab UI + 交互切换 │ └──► 机器层：MD / JSON └── 各 Tab 组合 → H3 + 正文 chunk └── 禁止依赖 display:none 隐藏面板
