隐藏的语义（Tab）

本页以 CANN 软件下载 为分析基准。Tab 隐藏语义指被交互 UI 折叠、未进入默认抓取管道的正文——非激活 Tab 面板常被 display:none 隐藏。用户切换 Tab 能看到的选型说明与安装步骤，知识库可能只入库当前默认 Tab 组合。

抓取差
核心问题
  • CANN 软件下载 页含多轴 Tab 选型（版本、架构、发行版、在线/离线安装等），非激活面板可被 CSS 隐藏——默认抓取可能只抓到当前 Tab 组合下的安装说明

问题实测

测试问题

读取 CANN 软件下载（CANN 9.0.0），切换版本 / 架构 / 发行版 / 安装方式等 Tab 后，非激活 Tab 面板内的选型说明与安装命令是否进入了知识库？

结论：非激活 Tab 语义未入库或截断

CANN 软件下载页是典型的多轴 Tab 场景。页面在版本、架构、发行版、安装方式等维度上组合切换；渲染页中非激活面板正文与部署命令可能不在默认可见 DOM 中，默认管道跳过 display:none 区域时，知识库可能仅有「在线安装 · x86_64 · 9.0.0」一类当前组合，缺少离线安装、其他架构等分支说明。

CANN 软件下载 → 多轴 Tab 隐藏非激活面板

CANN 软件下载 通过多组 Tab 组织选型与安装步骤：用户需切换版本、架构、发行版、在线/离线安装等 Tab 才能看到完整命令与说明。默认抓取若只读当前激活面板，其余组合的 wget / 安装脚本等正文等价于未入库。

<div class="tab-hover"> <!-- 当前可见：在线安装 · x86_64 · CANN 9.0.0 --> <div class="tab-panel-active">...wget / ./Ascend-cann-toolkit... --install</div> <!-- display:none：离线安装 / 其他架构 Tab 面板 --> <div class="more-tab-item" style="display:none"> <pre>...离线包安装命令...</pre> </div> </div>

实测可归纳为三点（均在说「默认抓取只看见当前 Tab，其余分支进不了知识库」）：

  • 当前选中的 Tab 组合（如在线安装 · x86_64 · 9.0.0）——对应安装命令可能入库，但只是全部组合中的一条路径。
  • 未选中的 Tab 组合（离线安装、aarch64、其他发行版等）——面板在 display:none 中，默认管道完全跳过，chunk 中不存在。
  • Tab 标签与选型维度——往往未结构化写入 chunk，检索时难以区分「用户问的是哪条安装路径」。

改抓 /doc_center/source/ 或在机器层预展开全部 Tab 组合，才能避免上述截断；详见解决方案。

解决方案

改进目标

让每个 Tab 组合下的选型说明与安装命令以独立文本 chunk进入知识库——检索「CANN 离线安装」「aarch64 下载命令」时均能召回，不要求用户在线切换 Tab，要求机器层事先全量展开。

改进措施

1. 推进内容侧：Tab 全量文本化 P0

  • 源 HTML 中所有 Tab 面板完整存在，不依赖 JS 懒加载——抓取不遗漏任一 Tab 正文。
  • 每个 Tab 有明确文本标签——chunk 可区分「在线安装」与「离线安装」、「x86_64」与「aarch64」等组合。
  • 机器层全部展开，用 H3 标注各 Tab 标题——扁平 MD 中各选型组合均可检索。
  • 禁止在源 HTML 用 display:none 隐藏非默认 Tab——源层与机器层一致，无隐藏截断。

核心原则：Tab 内容先行入库——每个 Tab 须有可读标签，正文在源 HTML 中顺序展开。RAG 应优先消费 /doc_center/source/ 或预生成 MD，而非依赖渲染页隐藏区域。详见 亲和原则 · Tab 语义。

2. 落实架构侧：双轨交付 + 端点优先级

针对多 Tab 含安装命令：各组合扁平展开后再入库；针对Tab 标签进元数据：chunk 标注 tab_label 字段（如版本、架构、安装方式）。双轨交付——人类层保留 Tab 交互，机器层消费源 HTML 或预展开 MD：

HTML 源（doc_center） │ ├──► 人类层：多轴 Tab UI + 交互切换（体验不变） │ └──► 机器层：MD / JSON + llms.txt └── 优先消费 /doc_center/source/（4–11 KB） └── 各 Tab 组合扁平为 H3 + 正文 chunk └── 禁止依赖 /cann/download 渲染页 display:none 区域

RAG 管道应声明抓取端点；Tab 语义在发布环节全量展开，而非检索时模拟点击 Tab。
