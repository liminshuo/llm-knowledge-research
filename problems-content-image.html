图片图意 未入库

图片图意指信息型图片所承载、但未写成正文的文档语义——知识库入库时应转写为可检索、可引用的文本 chunk。 以 什么是 Ascend C 为例：若仅入库 PNG 文件名或图片二进制，API 分层、成长地图阶段等图意视为未入库。

3. 问题洞察

大模型的回答指向两点结论：

  • 图意未入库：6 张信息型 PNG 在转文本管道中完全不出现在 chunk 中——API 分层、成长地图等图意对人类可见，对 RAG 不可见。
  • 仅有文件名：HTML 仅见 zh-cn_image_xxx.png，无 alt 与内容转写——问「API 有几层」时知识库无对应 chunk。

根因分析

图片图意丢失的核心原因是：无 alt、无内容转写、装饰图与信息图未区分。

1. 无 alt 语义

<img> 仅有 PNG 文件名，入库 chunk 不含图意描述。

修改建议

为信息型图片写有意义 alt 与 figcaption。

2. 图意未转写正文

架构图、成长地图等关键信息只存在于像素里，未写为可检索段落。

修改建议

图下补充「图片内容转写」段落，或成长地图用正文 <ol> 列表（详见 图片内容转译）。

3. 装饰图未标记

纯装饰 PNG 与信息图混排，管道无法区分优先级。

修改建议

装饰图标标记 aria-hidden 或改为文本，从机器层移除。

4. 缺可编辑图源

架构 / 流程图仅有位图，无法结构化解析。

修改建议

提供 Mermaid / SVG 可编辑源，入库优先解析（见 亲和原则）。
