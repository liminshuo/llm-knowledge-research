注意提示（Note）类型语义 正文可抓

注意提示类型语义指 note / warning / caution / tip 等提示级别对模型是否可识别——notebody 正文可获取，但装饰图标无文本。 以 环境准备 为例：模型不知道这是「注意」还是「警告」，也无法按类型过滤检索。

问题实测

1. 向模型提问

我在看 环境准备（CANN 9.0.0），安装完 CANN 之后环境变量要怎么配？文档是用「注意」还是普通正文来提示的？

2. 大模型回答

查看大模型回答内容

3. 问题洞察

大模型的回答指向两点结论：

  • 正文可抓、类型语义缺失：notebody 正文能入库，但提示类型（注意 / 警告）仅靠图标 PNG，不产生可检索文本。
  • 与正文难区分：问「有哪些注意事项（注意级别）」时，chunk 缺少类型标签，RAG 无法按「注意 / 警告」过滤。

根因分析

Note 语义缺失的核心原因是：无 admonition 类型字段、图标代替文字前缀、提示未转写为引用块。

1. 无类型字段

源码无 data-admonition-type，入库后 Note / Warning 不可区分。

修改建议

标注 data-admonition-type="note|warning|danger"。

2. 图标代替文字

「注意：」语义靠 note_3.0-zh-cn.png 承载，转文本管道丢失。

修改建议

渲染页用「注意：」「警告：」文字前缀替代装饰图标。

3. 未转写引用块

提示未转为 Markdown blockquote，LLM 引用时缺级别前缀。

修改建议

机器层转为 > **注意** 格式保留类型与正文。

4. 嵌套层级丢失

嵌在 <ol><li> 内的提示被扁平化。

修改建议

抓取时保留原始列表层级（见 安全警示语义化）。
