# Ascend C 开发者 · 用户旅程与 AI 输入

> 内部参考：按阶段梳理开发者从「了解昇腾」到「深度排障」的典型意图与向 AI 的提问方式。  
> **不纳入站点 HTML 导航**；与 [问题论证](../problems-answer-search.html) 的实测维度对照使用。

---

## 1. 落地.找入口.选型（感知了解阶段）

**用户意图：** 了解 Ascend C 算子开发，能做什么

**典型 AI 输入：**

- 华为昇腾 AI 开发框架是什么？
- 昇腾和 CUDA 的区别？
- 昇腾能跑哪些模型？

---

## 2. 上手引导（学习知识阶段）

**用户意图：** 学习 Ascend C 入门与文档阅读

**典型 AI 输入：**

- Ascend C 入门教程
- 帮我解释 CANN 文档中的 XXX 概念
- 给我一个 Ascend C Hello World 示例

---

## 3. 配环境.拿SDK（环境准备阶段）

**用户意图：** 安装 CANN、配置 SDK 环境

**典型 AI 输入：**

- CANN 9.1 在 CentOS 7.6 上的安装步骤
- Ascend-cann-950-ops 安装报错怎么解决？
- 帮我生成 CANN 环境配置脚本

---

## 4. 手动写算子（核心开发阶段）

**用户意图：** 手动编写 Ascend C 算子

**典型 AI 输入：**

- 用 Ascend C 实现一个 ReLU 算子
- 帮我补全这个 kernel 函数
- Ascend C 中如何使用 LocalTensor？

---

## 5. 编译跑通（验证结果阶段）

**用户意图：** 编译跑通并验证结果

**典型 AI 输入：**

- 粘贴编译报错日志
- ascendc compile error: undefined reference...
- 算子输出全为 0，可能是什么原因？

---

## 6. 调试求助（深度排障阶段）

**用户意图：** 性能优化与运行时排障

**典型 AI 输入：**

- Ascend C 算子运行时 SIGSEGV 怎么排查？
- 帮我分析这个 dump 文件
- 如何优化 Ascend C 算子的搬运效率？

---
