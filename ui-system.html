正文与说明

全局正文

全局正文 14px，行高 22，颜色 #595959（--color-text-secondary）。段落下边距 12px。

代码文案

段落与列表中的行内 code 统一高度 20px（13px 字号 + 16px 行高 + 上下 2px padding）。示例：<img>、alt、data-llm-transcription。

文案解释

术语或缩写加虚线下划线，悬停显示释义。示例：大模型 RAG / 知识库。

小节标题 语义完全丢失

  • 必要alt：图片标签上缺图片说明
  • 可选title：图片标签上缺可用的标题说明

当前以抓取 什么是 Ascend C（CANN 9.0.0） 为例，正文区 6 张说明图对向量检索和 LLM 引用而言，等价于空白。具体实测见 问题论证 · 图片图意。

全站正文内容区最大宽度 1000px（1920 视口下）；视口变窄时自适应缩小。

令牌 / 类名值说明

--content-main-pad-leftclamp(24px, 10.4167vw, 200px)有侧栏内页：正文距 main 左缘（1920 下 200px）
--content-main-pad-topclamp(32px, 2.5vw, 48px)内页 main 上内边距（1920 下 48px，H1 顶对齐）
