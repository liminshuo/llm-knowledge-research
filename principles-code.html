代码块语义化

代码块标注语言与场景、分离行号、还原 HTML 实体，确保入库源码干净可直接复用。 读的懂 · 序号 8 · 对应 问题论证 · 代码语义。

设计UI调整

调整建议

  • 定义代码块组件规范：设计代码块组件，包含：a. 顶部元信息栏（文件名、语言类型、适用场景，如 hello_world.cu | C++ | 基础编译场景）；b. 代码区（行号由 CSS 渲染，不出现在可选中文本中）；c. 底部预期输出块（执行类代码必须配套，样式与代码块区分）；d. 右上角复制按钮。纳入设计系统组件库。
  • 预期输出块样式设计：预期输出块与代码块视觉上明确区分，标题固定为"预期输出"，不使用"输出结果""运行结果"等变体，纳入格式规范。
  • 元信息文案交付：内容交付时，每个代码块同步提供：文件名（如有）、语言类型、适用场景描述（一句话）、预期输出内容。

文档内容调整

调整建议

  • 独立可运行：代码示例应尽可能自包含，用户可以复制后直接运行。 b.
  • 语言标注：每个代码块必须标注编程语言（如 python、cpp）。 c.
  • 注释清晰：关键行应包含注释，解释其作用。 d.
  • 预期输出：对于执行类代码，应在代码块后提供"预期输出"块。 e.
  • 格式分离：代码行号应由前端CSS或代码高亮库生成，严禁在代码文本中手动写入行号。 f.
  • 区块语义：代码块应使用 <pre><code> 语义标签包裹。

调整示例

1. 语言标注 + 预期输出块

Before · 无语言标注，无预期输出

```
__aicore__ inline void Add(...) {
    Add(z, x, y, TILE_LENGTH);
}
```

After · 语言 + 注释 + 预期输出

```cpp
// kernel_add.cpp · Ascend C · 矢量加法算子示例
__aicore__ inline void Add(
    const LocalTensor<float> &z,
    const LocalTensor<float> &x,
    const LocalTensor<float> &y) {
    Add(z, x, y, TILE_LENGTH); // 执行向量加法
}
```

**预期输出：**

```
[INFO] kernel Add executed successfully.
```

前端调整

调整建议

  • <pre><code> 语义结构实现：所有代码块使用 <pre><code> 包裹，<code> 上标注 language-xxx 类名，禁止使用 highlighttable 表格布局。
  • 行号 CSS 渲染，禁止写入文本节点：行号通过 CSS counter 实现，不写入 <code> 文本内容，确保复制代码时不包含行号，切片管道拿到的是纯净代码文本。
  • HTML 实体解码：切片管道入模前，将代码文本中的 HTML 实体还原为可读字符。
  • 弃用 highlighttable 布局：将现有使用 highlighttable 表格承载代码的结构全部迁移为 <pre><code> 结构；构建管道中加入检测，发现 highlighttable class 时阻断发布。
  • Chunk 切片管道追加规则：提取 <code class="language-xxx"> 的语言类型作为 chunk 元数据；提取 .code-meta 内的文件名和场景描述，拼接到代码 chunk 头部；code-output 块与对应代码块绑定为同一 chunk，不拆分。
