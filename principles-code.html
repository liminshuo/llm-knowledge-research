代码语义

对应 当前问题 · 代码语义。代码块须纯净可复制，行号与语法高亮不得污染正文。

亲和原则

编号原则描述级别调整层面
1源码使用 pre > code 并标注 language-xxx必须源码
2渲染页行号与代码分离，行号不写入 code 文本节点必须UI 源码
3弃用 highlighttable 表格布局渲染代码块必须UI 源码
4代码块上方在渲染页标注文件名、语言、适用场景建议UI 源码
5管道入模前解码 &lt; 等 HTML 实体必须管道
