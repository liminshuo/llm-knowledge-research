隐藏的语义（折叠面板） 抓取差

折叠隐藏语义指默认收起区内的正文——用户需点击展开才能看到的硬件确认指引，默认抓取常只入库标题、丢失区内步骤。 以 CANN 软件下载 中的「我不知道硬件信息」折叠面板为分析聚焦。

核心问题
  • 「我不知道硬件信息」面板区内收纳硬件确认与选型指引，默认收起时正文不在可见 DOM 中
  • 默认管道跳过 display:none 区域，chunk 中可能仅有标题七个字，没有可执行步骤
  • 与 Tab 选型 叠加时，「不知硬件 → 不知如何选型」链路在知识库中断裂

问题实测

测试问题

我在看 CANN 软件下载（CANN 9.0.0），不太确定自己的昇腾硬件型号，应该怎么确认并选对的 CANN 安装包？

结论：折叠区语义未入库或截断

「我不知道硬件信息」面板是典型的默认折叠场景。标题在页面上可见，但区内「如何查型号、如何对照配套关系、应选哪类 CANN 包」等指引收纳在折叠体内。默认抓取跳过 display:none 区域时，区内正文对 RAG 不可见——与用户点击展开后看到的内容存在系统性差异。

折叠语义对照

折叠要素页面上入库后
折叠标题「我不知道硬件信息」可见可能入库（alone 无法回答）
折叠正文（默认收起）display:none 隐藏完全缺失
硬件确认步骤展开后可见 npu-smi info 等指引未入库
与 Tab 选型关系同页多轴 Tab 交互链路断裂（见 Tab）

入库状态对照

入库环节状态说明
折叠标题文本部分入库无区内步骤
折叠区正文未落实管道跳过隐藏节点
折叠全量展开缺失须机器层预展开
硬件选型指引丢失须源 HTML 默认可见

解决方案

改进目标

让「我不知道硬件信息」面板内的硬件确认与选型指引以可检索文本 chunk 进入知识库——用户问「不知道硬件型号怎么选 CANN 包」时能召回区内步骤，不要求在线点击展开。

改进措施

  • 必要折叠默认展开：标题具备语义，初始状态下面板区内正文完全展开；禁止通过 CSS 隐藏折叠内容；
  • 必要管道层扁平输出：在机器处理层将折叠内容全量展开，以 H3 标签标注各面板标题后入库；
  • 可选双轨交付：RAG 优先抓取预展开 MD，人类仍保留折叠交互 UI。

核心原则：折叠内容先行入库——机器可读层无「收起」状态。详见 亲和原则 · 折叠语义。
