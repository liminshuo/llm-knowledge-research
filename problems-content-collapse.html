隐藏的语义（折叠面板）

本页以 CANN 软件下载 中的「我不知道硬件信息」折叠面板为分析聚焦。折叠隐藏语义指默认收起区内的正文——用户需点击展开才能看到的硬件确认指引，默认抓取常只入库标题、丢失区内步骤。

抓取差
核心问题
  • 下载页提供「我不知道硬件信息」折叠入口，区内收纳「如何确认昇腾型号、如何匹配 CANN 版本」等指引；默认收起时区内正文不在可见 DOM 中——用户问「不知道硬件该下哪个包」时，知识库可能没有对应 chunk

问题实测

测试问题

读取 CANN 软件下载（CANN 9.0.0），不展开「我不知道硬件信息」面板，模型能否回答：「我不清楚自己的昇腾硬件型号，应该怎么确认并选择正确的 CANN 软件包？」

结论：折叠区语义未入库或截断

「我不知道硬件信息」面板是典型的默认折叠场景。标题在页面上可见，但区内「如何查型号、如何对照配套关系、应选哪类 CANN 包」等指引收纳在折叠体内。默认抓取跳过 display:none 区域时，区内正文对 RAG 不可见——与用户点击展开后看到的内容存在系统性差异。

「我不知道硬件信息」→ 区内指引默认不可见

该面板面向尚未确认昇腾产品型号的用户：展开后通常提供设备查询方式（如 npu-smi info）、产品型号与 CANN 版本配套说明、Atlas 系列选型提示等。折叠体默认 display:none，多数 HTML→文本管道不遍历隐藏节点——chunk 中可能仅有「我不知道硬件信息」七个字，没有可执行的确认步骤。

<div class="collapse"> <div class="collapse-header">我不知道硬件信息</div> <div class="collapse-body" style="display:none"> <p>执行 npu-smi info 查看 Chip Name…</p> <p>对照产品型号与 CANN 版本配套关系…</p> </div> </div>

实测可归纳为三点：

  • 折叠标题——「我不知道硬件信息」可能入库，但 alone 无法回答如何确认型号。
  • 折叠正文（默认收起）——硬件确认步骤、配套对照说明在 display:none 中，默认管道完全跳过。
  • 与 Tab 选型的关系——同一页还需先选对版本 / 架构 / 安装方式（见 Tab 隐藏语义）；折叠区丢失会让「不知硬件 → 不知如何选型」的链路在知识库中断裂。

机器层预展开该面板，或在源 HTML 中将区内指引改为默认可见正文，才能避免上述截断；详见解决方案。

解决方案

改进目标

让「我不知道硬件信息」面板内的硬件确认与选型指引以可检索文本 chunk 进入知识库——用户问「不知道硬件型号怎么选 CANN 包」时能召回区内步骤，不要求在线点击展开。

改进措施

1. 推进内容侧：折叠默认展开 P0

  • 机器层默认展开「我不知道硬件信息」面板——区内硬件确认步骤全部进入 chunk。
  • 折叠标题用 <h3> 或 <summary>——与区内正文形成完整问答单元。
  • 不用 display:none 隐藏区内指引——源层与抓取结果一致。
  • 原生 <details> 添加 open 属性，或机器层单独输出该段为正文列表。

核心原则：折叠内容先行入库——机器可读层无「收起」状态。详见 亲和原则 · 折叠语义。

「我不知道硬件信息」改造示例

❌ 当前：默认收起

<div class="collapse"> <div class="collapse-header">我不知道硬件信息</div> <div class="collapse-body" style="display:none"> 执行 npu-smi info 查看 Chip Name… </div> </div>

知识库 chunk：仅见标题，无法回答「如何确认硬件型号」。

✅ 改造后：源层 + 机器层展开

<details open data-llm-expanded="true"> <summary><h3>我不知道硬件信息</h3></summary> <ol> <li>登录设备执行 <code>npu-smi info</code>，查看 Chip Name / 产品型号</li> <li>对照昇腾社区「产品型号与 CANN 版本配套关系」文档</li> <li>按确认结果选择对应 CANN 社区版与驱动包</li> </ol> </details>

知识库 chunk：可检索「不知道硬件信息」「npu-smi 查型号」「CANN 版本配套」。

机器层 Markdown 输出要点

### 我不知道硬件信息 1. 登录设备执行 `npu-smi info`，查看 Chip Name / 产品型号 2. 对照昇腾社区「产品型号与 CANN 版本配套关系」文档 3. 按确认结果选择对应 CANN 社区版与驱动包

2. 落实架构侧：双轨交付

双轨交付——人类层保留折叠入口节省版面，机器层预展开「我不知道硬件信息」及同页其他折叠区：

HTML 源（doc_center / 下载页源） │ ├──► 人类层：折叠 / 手风琴 UI（体验不变） │ └──► 机器层：MD / JSON + llms.txt └── 「我不知道硬件信息」→ H3 + 步骤列表 chunk └── 剥离 display:none 依赖

折叠语义在发布环节展开完毕；RAG 不模拟用户点击「我不知道硬件信息」。
