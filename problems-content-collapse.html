隐藏的语义（折叠面板）

折叠隐藏语义指默认收起面板内的步骤说明、代码与表格——折叠区常被 display:none 或手风琴组件隐藏。用户展开能看到 ≠ 知识库读得到；入库后即丢失，检索无法召回折叠区内正文。

抓取差
核心问题
  • 全站渲染页约 34 处 display:none，含折叠面板、Tab 等非默认可见区域——默认管道跳过隐藏节点
  • 四页实测样本中折叠使用较少，但全站广泛存在 collapse / accordion 模式；一旦默认收起，区内步骤与代码不在抓取输出中
  • 与 Tab 隐藏 同属「交互/UI 隐藏」维度——人类靠点击展开，模型无「点击」能力

测试问题

读取含折叠面板的昇腾文档页（如环境准备中的可折叠配置说明、或全站 accordion 组件页），默认折叠区内的环境变量设置步骤、详细参数说明是否进入了知识库？不手动展开页面，模型能否回答「set_env.sh 在什么步骤下需要执行」？

结论：折叠区语义未入库或截断

折叠面板是模型抓取的头号敌人之一。默认抓取跳过 display:none 区域时，折叠区内正文、代码块、嵌套表格对 RAG 不可见——与用户展开后看到的内容存在系统性差异。

1. 默认折叠 → DOM 隐藏

折叠/手风琴组件通常将 collapse-body 设为 display:none 或 visibility:hidden，直至用户点击标题展开。多数 HTML→文本管道不遍历隐藏节点，折叠区内容不出现在 chunk 中。

<div class="collapse"> <div class="collapse-header">高级配置</div> <div class="collapse-body" style="display:none"> <p>执行 source ${INSTALL_DIR}/set_env.sh ...</p> </div> </div>

2. 四页实测 vs 全站模式

本次四页样本（什么是 Ascend C、环境准备、HelloWorld、编程模型概述）未大量使用折叠面板，但环境准备等页存在步骤 + 注意提示的嵌套结构；全站其他章节广泛采用折叠收纳次要步骤、高级参数、故障排查等——这些语义在默认抓取中同样面临丢失风险。

页面类型折叠内容示例入库风险
环境准备类安装子步骤、环境变量详细说明高
算子开发类高级编译选项、调试参数高
API 参考类可选参数、返回值细节中

3. 与 Tab 隐藏的共性

折叠与 Tab 隐藏 均依赖 CSS/JS 控制可见性。全站渲染页统计约 34 处 display:none（见 交付格式），折叠与 Tab 是主要来源。差异在于：Tab 通常保留默认面板可见，折叠则默认全部隐藏，丢失比例更高。

4. 嵌套内容的连锁丢失

折叠区内常嵌套代码块、表格、注意提示。一旦外层折叠未展开入库，内层语义一并丢失——例如折叠区内的 set_env.sh 说明、CMake 可选参数表、警告类提示等，均无法被独立检索。

入库状态对照

入库环节折叠语义状态说明
折叠标题（header）部分可抓可见标题可入库，但无区内正文
折叠正文（默认收起）完全丢失display:none 被管道跳过
折叠区内代码块完全丢失连带 代码语义 一并缺失
折叠区内注意提示完全丢失连带 提示类型 一并缺失
机器层默认展开（COLL-01）源站缺失发布环节未扁平化输出

改进目标

让折叠面板内的全部正文以可检索文本 chunk进入知识库——检索「环境变量配置」「高级编译参数」时能召回折叠区内步骤，不要求用户在线展开，要求机器层默认全量展开。

改进措施

一、内容侧：折叠默认展开（P0，治本）

核心原则：折叠内容先行入库——机器可读层无「收起」状态。详见 亲和原则 · 折叠语义。

做法入库效果
1 机器层默认「展开」（COLL-01） 全部步骤与代码进入 chunk
2 折叠标题用 <h3> 或 <summary>（COLL-02） chunk 边界清晰，可检索标题
3 不用 display:none 隐藏正文（COLL-03） 源层与抓取结果一致
4 <details> 添加 open 属性（COLL-04） 源 HTML 默认态即展开

折叠面板改造示例

❌ 当前：默认收起

<div class="collapse"> <div class="collapse-header">配置环境变量</div> <div class="collapse-body" style="display:none"> source ${INSTALL_DIR}/set_env.sh </div> </div>

知识库 chunk：可能仅有标题「配置环境变量」，无 set_env.sh 命令。

✅ 改造后：源层 + 机器层展开

<details open data-llm-expanded="true"> <summary><h3>配置 CANN 环境变量</h3></summary> <p>执行 <code>source ${INSTALL_DIR}/set_env.sh</code> 设置环境变量。</p> </details>

知识库 chunk：可检索「set_env.sh」「环境变量配置步骤」。

机器层 Markdown 输出要点

### 配置 CANN 环境变量 执行 `source ${INSTALL_DIR}/set_env.sh` 设置环境变量。

二、架构侧：双轨交付

双轨交付——人类层保留折叠交互节省版面，机器层预展开全部内容：

HTML 源（doc_center） │ ├──► 人类层：折叠 / 手风琴 UI（体验不变） │ └──► 机器层：MD / JSON + llms.txt └── 所有折叠区扁平为 H3 + 正文 └── 剥离 display:none 依赖 └── 嵌套代码 / 表格 / 提示一并展开

折叠语义在发布环节展开完毕；RAG 不模拟用户点击。

改进路径

场景建议优先级
