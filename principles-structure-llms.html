llms.txt / sitemap 部署

在站点层部署机器发现层（llms.txt、llms-full.txt、sitemap.xml、robots.txt），声明机器应从哪条 URL 抓取、主推哪一版文档。同时在人类浏览页提供可见的「机器可读版本」入口，避免 Agent 与合规爬虫只能沿渲染页路径抓取。 找的到 · 序号 1 · 对应 实测问题 · 机器发现层缺失 · 完整条目见 全量亲和原则 #1。

设计UI调整

调整建议

  • 「机器可读版本」入口：增加固定入口，文案明确为「机器可读版本（source HTML）」或类似表述，禁止用泛化图标替代文字链接。
  • 入口样式规范：该入口视觉权重与页脚其他导航链接一致，不突出也不隐藏，全站样式统一。

人类可点进机器源；爬虫与 Agent 获得明确跳转信号。

前端调整

调整建议

  • 部署 /llms.txt：按产品线-版本分组，构建管道从 CMS 文档元数据自动生成，文档发布时自动更新，不依赖人工维护。
  • 部署 /llms-full.txt：构建管道从 /doc_center/source/ 自动聚合所有索引文档的 Markdown 全文为单文件，随文档发布自动重新生成。
  • <head> 中注入机器发现标签：每个页面自动输出 <link rel="llms" href="/llms.txt"> 和 <link rel="alternate" type="text/markdown" href="对应 source 路径">，由页面模板统一生成。
  • sitemap.xml 优先收录 source 路径：/doc_center/source/ 下的机器源路径优先级（priority）高于渲染页，lastmod 字段从文档 dateModified 自动同步。
  • robots.txt 配置：放行 source/ 路径，禁止爬取 /assets/、/api/，文件末尾指向 sitemap.xml，引导爬虫走机器源路径。

调整示例

1. <head> 机器发现标签

Before

HTML 源码

<head>
  <title>Ascend C 算子开发</title>
  <link rel="canonical" href="/document/detail/.../operator_dev.html">
</head>

无 llms / alternate 声明，Agent 只能沿用人类渲染页 URL。

After

HTML 源码

<head>
  <title>Ascend C 算子开发</title>
  <link rel="llms" href="/llms.txt" type="text/markdown">
  <link rel="alternate" type="text/markdown"
        href="/doc_center/source/zh/CANN/900/operator_dev.md">
  <link rel="canonical" href="/doc_center/source/.../operator_dev.md">
</head>

页面级声明站点索引与本文机器源，模板统一输出。

2. robots.txt

Before · 封锁机器源

robots.txt

User-agent: *
Disallow: /doc_center/
Disallow: /assets/

Sitemap: https://www.hiascend.com/sitemap.xml

sitemap 声明有文档，robots 却封死 /doc_center/，爬虫拿到链接后直接被拦截。

After · 放行机器路径

robots.txt

User-agent: *
Allow: /doc_center/source/
Disallow: /assets/
Disallow: /api/

Sitemap: https://www.hiascend.com/sitemap.xml

机器源与 llms 入口可抓；噪声路径与追踪参数屏蔽。

3. sitemap 收录策略

Before · 只收录渲染页

sitemap.xml 片段

<url>
  <loc>https://www.hiascend.com/document/detail/.../operator_dev.html</loc>
  <priority>0.5</priority>
</url>

收录 ~224 KB 渲染壳层，导航栏等噪声稀释正文语义。

After · 优先 source 路径

sitemap.xml 片段

<url>
  <loc>https://www.hiascend.com/doc_center/source/zh/CANN/900/operator_dev.md</loc>
  <lastmod>2026-06-01</lastmod>
  <priority>0.9</priority>
</url>

机器源优先索引；lastmod 与文档 dateModified 自动同步。
