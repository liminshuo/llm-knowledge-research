.md vs .html 实测

同一页面两种 URL 在昇腾社区实测下的差异。

要点三：.md 形式与 .html 形式，哪个对大模型更友好？

结论（昇腾社区实测）
在当前社区实现下，同一「什么是 Ascend C」页面： .html 链接对大模型反而比 .md 链接更友好——但这不代表 HTML 优于 Markdown， 而是说明两种 URL 都是 SPA 渲染页，.md 管线的文本丢失更严重。 真正的最优解是独立的纯 Markdown / 源 HTML 出口（/doc_center/source/）。
