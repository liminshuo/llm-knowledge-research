图片热区

图片热区指 <img usemap> + <area href> 把跳转目标绑在坐标上的导航方式。对人类是「点图跳转」，对默认 RAG 管道则是藏在像素坐标里的链接——若不冗余为文本链接列表，热区语义无法进入知识库。

完全丢失
核心问题
  • 「什么是 Ascend C」页全页共 28 个热区，成长地图单图 14 个——转文本管道下跳转关系全部丢失
  • 解析 HTML 可抽出 area href，但默认 RAG 通常不做；多数热区无 alt、无 title，链接缺少可读标签
  • 热区恢复的是链接目标而非图片图意；须与图意转写配合，链接文本规范见 链接语义

测试问题

读取 什么是 Ascend C（CANN 9.0.0），成长地图里的跳转链接你能拿到吗？环境准备、HelloWorld 等入口在知识库里能检索到吗？

结论：热区链接未入库

人类可点图跳转，默认 RAG 拿不到热区链接语义。用户问「Ascend C 学完环境准备下一步看什么」「成长地图有哪些阶段入口」时，知识库中没有对应链接 chunk 可召回——跳转目标对人类可见，对检索不可见。

1. 常规抓取 → 热区 chunk 不存在

页面转 Markdown / 纯文本时，<map> 与 <area> 完全不在输出里。正文区 5 张带 usemap 的信息型图在转文本管道中连同热区一并消失——不是「链接劣化」，而是知识库中根本没有承载跳转关系的文本块。

2. 解析 HTML → 只见坐标与裸 href

深入解析 HTML 时，热区以坐标 + 相对路径形式存在，几乎无可用链接文本：

热区图HTML 特征入库后可见内容
成长地图 usemap="#d90300e79"，14 个 area，多数无 title 裸 href（如 atlas_ascendc_map_10_0003.html）；阶段名称未转写
快速入门 / 概念原理 / API 参考 / 算子实践（4 张卡片图） 均带 usemap，area 仅坐标 + href 卡片入口链接未附可读标签
全页合计 28 个 <area> 标签 默认管道不解析时等价于零链接

典型抓取结果仅为：

<img usemap="#d90300e79" src=".../zh-cn_image_0000002562432937.png">

对向量检索与 LLM 引用而言，这等价于空白链接 chunk。

以下跳转目标只存在于热区坐标中，当前文档未提供文本链接冗余，入库后即丢失：

热区 href（节选）丢失的链接语义

少数 area 带 title（如「通过 printf 打印数据」），但不成体系，且默认转文本管道仍不会保留。

4. 解析 HTML ≠ 热区自动入库

即便手工解析出 28 条 area href，「入库」还要求每条链接有可检索文本标签（阶段名、目标文档标题）。裸文件名对向量检索几乎无意义；须在源站或机器层冗余为 <nav> / 列表链接。

入库状态对照

入库环节热区状态说明
正文段落链接已入库带锚文本的 <a> 可检索
热区（转文本管道）完全丢失map / area 不出现在 chunk 中
热区（解析 HTML）部分可见可见 href，缺可读标签；默认 RAG 通常不解析
热区文本冗余（nav 列表）源站缺失文档未提供，管道无法生成
入库管道专项解析 area可补救需定制管道，仍须补全链接文本

改进目标

让图片热区所承载的跳转关系以文本链接 chunk 进入知识库——用户检索「环境准备」「HelloWorld 入口」「成长地图下一阶段」时能召回对应 href 与目标语义。不要求在线点图，要求热区事先文本化冗余。

改进措施

一、内容侧：热区文本化（P0，治本）

核心原则：热区先行入库——图里每个可点击入口，页面上必须有可被抓取的文本链接等价物。详见 亲和原则 · 图片热区（IMG-03）、链接语义（L-04）。

做法入库效果
1 每张 usemap 图附 <nav> 文本链接列表（L-04） 产生可检索 chunk：「环境准备 → atlas_ascendc_map_10_0003.html」
2 链接文本用阶段/文档名，禁止裸 href（L-01） 高价值 chunk：「AI Core SIMD 编程」「算子实践参考」
3 机器层站内链接转绝对 URL（L-03） 链接目标可被 RAG 引用与跳转解析
4 与图意转写配合（IMG-02），不替代图意本身 阶段路径 + 入口链接双重可检索

二、架构侧：双轨交付

双轨交付——人类层保留热区点图体验，机器层预置链接列表：

HTML 源（doc_center） │ ├──► 人类层：PNG + usemap + 交互 UI（体验不变） │ └──► 机器层：MD / JSON + llms.txt └── 每张热区图 → nav 文本链接列表 └── area href → 绝对 URL + 描述性锚文本

RAG 只消费机器层；热区入库在发布环节完成，而非检索时临时解析坐标。
