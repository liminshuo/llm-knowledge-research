跨页关系未结构化

对应研究概览第 8 节「信息架构与跨页语义」：breadcrumb、上下篇、父主题与章节间跳转在页面上对人类可见，入库后未标准化为 chunk 元数据与关系边——跨页 IA「有据、无情」。页级 version / doc_id 字段化论证见 页级元数据未结构化。

语义未结构化
核心问题
  • 模型难以判断「环境准备」指向入门教程还是软件安装——缺乏 breadcrumb 消歧
  • 成长地图 28 个热区链接丢失，无法感知章节间跳转与学习顺序
  • 多版本文档（8.5 / 9.0）并存，跨页关系未与 version 绑定，检索时版本混淆
  • 全站 282 项导航菜单若灌入上下文，造成 IA 过载；若不灌入，又缺乏跨页关联
  • 上下篇、父主题链接存在但机器层未标准化输出

问题实测

测试问题

向量库已入库 Ascend C 文档正文后，能否回答：

  • 检索「环境准备」时，它属于入门教程还是软件安装？
  • 读完「什么是 Ascend C」后，下一篇应读什么、成长地图各阶段如何跳转？
  • 引用某 chunk 时，能否回溯到唯一章节路径而非仅 URL？

结论：跨页关系未结构化

人类在渲染页能看见章节位置，RAG 读不到关系边。 breadcrumb 压缩在 <title> 字符串里、上下篇未进 Front Matter、成长地图热区未转写——chunk 之间没有可检索的 prev / next / parent_topic，多跳推理与学习顺序推理失败。

1. breadcrumb 有文本、无字段

以「什么是 Ascend C」为例（hiascend-metadata-probe.md）：章节路径存在于 URL 与 <title>，但未拆成 breadcrumb[] 数组写入 chunk。同名「环境准备」在不同教程线下无法字段消歧。

关系信息页面上入库后
章节路径✅ 压缩在 title / URL❌ 无 breadcrumb 字段
父主题✅ 侧栏树可见❌ 未写入 parent_topic
上下篇⚠️ 部分页脚有链接❌ 无 prev / next

2. 成长地图：章节关系只存在于热区

「什么是 Ascend C」成长地图含 28 个热区跳转——对人类是导航图，对默认抓取管道是 PNG + 坐标（见 图片热区）。即使正文段落可检索，阶段顺序与章节间跳转仍无法从 chunk 关系边还原。

3. IA 层级：灌全站 vs 不灌都错

IA 层级内容跨页 / 单文档当前入库态
Level 0单页正文单文档基本可用
Level 1breadcrumb、上下篇、版本跨文档未结构化
Level 2章节子树（入门教程完整路径）跨文档缺失
Level 3全站 282 项导航跨文档噪声灌库（若抓渲染页）
论证链
机器发现层 引导爬虫抓渲染页 → 282 个导航链接与正文混排 → Level 1 关系反而未字段化 → 与 多版本消歧、检索阶段 观测一致。

入库状态对照

入库环节跨页关系状态说明
渲染页剥壳抓取Level 3 噪声侧栏全站树与正文混排
title 路径字符串未结构化无法字段消歧、无法过滤
Front Matter 关系边源站缺失无 prev / next / breadcrumb 标准输出

解决方案

改进目标

每篇 chunk 入库时附带Level 1 跨页关系——breadcrumb、上下篇、父主题与版本绑定可检索；同时剥离 Level 3 全站导航，避免 282 项侧栏稀释正文。

改进措施

推进 UI 侧：面包屑与上下篇可见 P0

  • 渲染页展示完整 breadcrumb 文本路径——消歧同名章节（如两处「环境准备」）。
  • 页脚或文首展示「上一篇 / 下一篇」，锚文本描述目标章节——人类可核对，管道可抽取。
  • 成长地图等热区入口须另有文本链接列表——章节关系不依赖读图（配合 图片热区）。

落实机器层：Front Matter 关系字段 P0

  • 每篇机器层输出 breadcrumb、prev、next、parent_topic——与渲染页可见导航一致。
  • version 与关系字段同批写入——跨页跳转不脱离版本上下文（字段模板见 页级元数据 · 解决方案）。
--- doc_id: atlas_ascendc_map_10_0002 breadcrumb: - Ascend C算子开发 - 入门教程 - 什么是 Ascend C prev: atlas_ascendc_map_10_0001 next: atlas_ascendc_map_10_0003 version: CANN社区版 9.0.0 ---

收敛管道：只保留 Level 1、剥离 Level 3 P0

  • 机器源从 /doc_center/source/ 抓取，自动剥离全站侧栏文档树——正文 chunk 不含 282 项导航链接。
  • 管道将关系边写入 JSON-LD / chunk 元数据——与 UI 层 breadcrumb 一致，供 RAG 过滤与多跳推理。
  • Level 2 章节子树按需输出为专题索引或关系边，不默认灌入每篇正文。

核心原则：轻量 IA 入库——不是把全站导航树灌进 chunk，而是每篇带上「我在哪、前后是什么」。详见 亲和原则 · 跨文档结构感知。
