跨页关系未结构化 语义未结构化

跨页关系指章节之间的 breadcrumb、上下篇、父主题——人读页面能看清位置，chunk 之间却没有可检索的关系边。 以 什么是 Ascend C 为例：路径挤在 <title> 里、上下篇未进 Front Matter——检索「环境准备」时分不清所属教程线。页级 version / doc_id 见 页级元数据未结构化。

3. 问题洞察

大模型的回答指向两点结论：

  • 跨页关系未结构化：人类在渲染页能看见章节位置，RAG 读不到 prev / next / parent_topic 关系边。
  • 同名章节难消歧：breadcrumb 压缩在 <title> 里——「环境准备」分不清入门教程还是安装文档；上下篇只能凭侧栏推断。

多跳推理与学习顺序推理因此失败，详见 页级元数据。

根因分析

跨页关系未结构化的核心原因是：breadcrumb 未拆分、上下篇未字段化、跨页关系未与 version 绑定。

1. breadcrumb 不可检索

章节路径挤在 <title> 字符串里，无可见面包屑——chunk 无法消歧同名章节。

修改建议

渲染页展示完整 breadcrumb，机器层写入数组字段。

2. 上下篇未字段化

侧栏树与页脚链接人类可见，Front Matter 无 prev / next。

修改建议

页脚或文首展示「上一篇 / 下一篇」，入库写入 prev / next / parent_topic。

3. 版本与关系未绑定

多版本文档并存，跨页链接未与 version 绑定——检索时版本混淆。

修改建议

跨页关系字段与 version 一并写入 Front Matter（见 页级元数据）。

4. 全站导航噪声

抓取渲染页时 282 项侧栏文档树灌库，淹没正文关系。

修改建议

机器源从 /doc_center/source/ 抓取，剥离 Level 3 导航（见 双轨交付）。
