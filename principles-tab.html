隐藏语义 · Tab

对应 问题论证 · 隐藏语义 · Tab。Tab 隐藏的面板须在源码完整存在，渲染层不得用 CSS 藏掉非激活项。

亲和原则

编号原则描述级别调整层面
1所有 Tab 面板内容在源 HTML 中完整输出，不依赖 JS 懒加载正文必须源码
2每个 Tab 标签在渲染页有明确文本（如「bisheng 编译」「CMake 编译」）必须UI 源码
3机器层将全部 Tab 展开，以 H3 标注各面板标题必须管道
4各 Tab 面板正文在渲染页全量可见（纵向排列展示，或切换 Tab 时不隐藏非激活项正文）必须UI
5渲染组件禁止用 display:none / visibility:hidden 隐藏非激活面板正文必须UI 源码
